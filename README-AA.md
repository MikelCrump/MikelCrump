# AA — Job Search Workspace

This repository branch is the **AA** workspace: a job-search operating system for **Mikel Crump**.

It is not a product app. Agents and chats named **AA** should only help with finding a job, using tools you connect (Gmail, Calendar, Drive, Notion, HubSpot, etc.).

## Start here

→ [`aa/README.md`](./aa/README.md)  
→ Agent rules: [`aa/AGENTS.md`](./aa/AGENTS.md) and root [`AGENTS.md`](./AGENTS.md)

## Connect tools

In Cursor → this agent → MCP / integrations, connect:

1. Gmail  
2. Google Calendar  
3. Google Drive  
4. Notion  
5. HubSpot (optional CRM)

Then tell AA what to do first (e.g. “scan my inbox for recruiter emails” or “log this application”).
