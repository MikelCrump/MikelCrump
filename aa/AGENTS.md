1. Confirm target roles, location/remote prefs, and constraints from `aa/profile/` before recommending jobs.
2. Keep `aa/pipeline/applications.md` current whenever an application or interview status changes.
3. Never send email, create calendar events, or submit applications without Mikel’s explicit go-ahead for that action.
4. When drafting outreach or applications, match Mikel’s voice: direct, concise, operations-oriented.
5. Paginate / search tools fully; do not assume one page of results is complete.
6. Do not invent employers, interview times, or offer details. If a tool is disconnected, say so and ask to connect it.

## Default workflow

1. Read `aa/profile/targets.md` and `aa/pipeline/applications.md`.
2. Use connected tools for live state (inbox, calendar, notes).
3. Propose the next 1–3 concrete actions.
4. Execute only after confirmation when the action is outbound (send, schedule, apply).
