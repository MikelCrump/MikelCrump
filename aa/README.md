# AA — Job Search Workspace

**Purpose only:** help Mikel find a job. Nothing else.

This workspace is the operating system for your job search. Work happens through tools you connect (email, calendar, drive, CRM, notes). Files here hold profile facts, pipeline state, and research so every AA session stays aligned.

## Scope (hard rules)

- In: roles, applications, outreach, interviews, offer comparison, resume/LinkedIn drafts, recruiter follow-ups
- Out: product builds, personal finance ops, unrelated coding, anything that is not job search

## Connect these tools

Connect (or reconnect) in Cursor MCP settings for this agent:

| Tool | Job-search use |
| --- | --- |
| **Gmail** | Recruiter mail, applications, follow-ups |
| **Google Calendar** | Interviews, networking, hold blocks |
| **Google Drive** | Resume, cover letters, portfolios |
| **Notion** | Pipeline board, company research, interview notes |
| **HubSpot** | People/company CRM if you track contacts there |

Optional later: LinkedIn exports in Drive, job boards you paste in chat.

## Folder map

| Path | Holds |
| --- | --- |
| `profile/` | Target roles, strengths, constraints, resume source of truth |
| `pipeline/` | Applications and status |
| `outreach/` | Networking and follow-up drafts |
| `research/` | Companies, roles, interview prep |

## How to work with AA

1. Connect the tools above.
2. Keep `profile/` accurate (titles, locations, salary floor, deal-breakers).
3. Ask AA to: scan inbox for recruiter mail, log applications, prep interviews, draft outreach, or plan the week.
4. AA updates `pipeline/` and related files when status changes.
